# llama.cpp для Windows — Установка, Обновление и Удаление

Комплект скриптов для развёртывания и обслуживания [llama.cpp](https://github.com/ggml-org/llama.cpp) на Windows в виде службы через [NSSM](https://nssm.cc). Сервер запускается как `llama-server.exe` с параметрами из INI. Оптимизирован под **NVIDIA RTX 4060 (8 ГБ VRAM)**, но работает на любом железе с подстройкой INI.

## Состав комплекта

| Файл | Назначение |
|---|---|
| `llama-windows-install.ini` | Единый конфиг (пути, сеть, версия, параметры llama-server) |
| `llama-windows-install.ps1` | Установка, обновление, переустановка и логирование |
| `llama-windows-uninstall.ps1` | Удаление службы и очистка |
| `README.md` | Этот файл (документация) |

Все четыре файла должны лежать в одной папке — например, `D:\AI\Llama.cpp\install`.

## Основные возможности

1. **Безопасная папка `install`.** Скрипты и лог-файл хранятся в `D:\AI\Llama.cpp\install`. При обновлении или переустановке эта папка **никогда не удаляется**.

2. **Защищённые папки внутри `LlamaCppDir`.** Следующие каталоги хранятся внутри `D:\AI\Llama.cpp` и не затрагиваются при обновлении:
   - `install\` — скрипты и лог
   - `logs\` — логи службы (с ротацией по `LogRetentionDays`)
   - `Downloads\` — кэш дистрибутивов (`llama_b<tag>\`, `cudart_b<tag>\`, `nssm_<ver>\`)
   - `Backup\` — бэкапы бинарников при обновлении
   - `Models\` — файлы моделей `.gguf`

3. **Умное обновление и переустановка.**
   - Скрипт определяет текущую версию (`b<NUM>`) и показывает меню со всеми релизами.
   - Текущая версия помечена как `(переустановка)` — её можно выбрать для полной переустановки.
   - **Выбор версии и подтверждение происходят в самом начале** — до остановки службы и создания бэкапов. Если нажать `s` в меню, служба продолжит работать без изменений.

4. **План действий.** Перед началом работы скрипт показывает сводку (текущая версия → целевая, режим, нужен ли бэкап, путь к модели) и просит финальное подтверждение `Продолжить? [Y/n]`.

5. **Описание службы.** В NSSM автоматически прописывается описание:
   > llama.cpp is a high-performance inference engine for large language models. This service exposes the llama-server HTTP API with CUDA acceleration.

6. **Очистка процессов.** Перед обновлением/удалением скрипт принудительно завершает процессы `llama-server`, чтобы избежать ошибки «Access denied».

7. **Безопасные права (SID).** Используется `*S-1-5-18` (SYSTEM) и `*S-1-5-32-544` (Administrators) для `icacls`, что гарантирует работу на любой локализации Windows.

8. **Логирование.** Все действия записываются в `llama-windows-install.log` (в папке со скриптом).

9. **Ротация логов.** Скрипт очищает файлы в `LogsDir` старше `LogRetentionDays` (по умолчанию 7 дней).

10. **Автообновление (`-Upgrade`).** Параметр позволяет запускать скрипт в Планировщике Windows для автоматической установки последней версии без интерактивных запросов.

11. **Диагностика.** При невозможности запустить службу скрипт выводит `ExitCode`, последние строки логов и результат `nssm dump`, а также пытается запустить `llama-server.exe` напрямую для выявления причины.

12. **Health-check через `GET /health`.** После запуска службы скрипт опрашивает `http://127.0.0.1:<Port>/health` и ждёт ответ `{"status":"ok"}`.

13. **NSSM в PATH.** Обе папки `NssmDir\win32` и `NssmDir\win64` добавляются в Machine `PATH` (при `AddNssmToPath=true`), так что `nssm` доступен из любой консоли без полного пути.

## Быстрый старт

1. Отредактируйте `llama-windows-install.ini`:
   - Проверьте `FirewallSubnet`.
   - Укажите **`Model`** — полный путь к файлу `.gguf` в секции `[server]`.
   - При необходимости измените `CtxSize`, `NGpuLayers`, `Parallel`.
2. Запустите `.\llama-windows-install.ps1`.
3. Если llama.cpp уже установлен:
   - Вы увидите текущую версию.
   - Меню покажет список релизов с пометкой `(переустановка)` на текущей.
   - Нажмите **`s`**, чтобы отменить — служба не будет остановлена.
   - Или выберите нужную версию (новую для обновления, текущую для переустановки).
4. Скрипт покажет «План действий» и спросит финальное `Продолжить? [Y/n]`.
5. Дождитесь завершения установки и проверки `/health`.

## Параметры запуска `llama-windows-install.ps1`

| Параметр | Описание |
|---|---|
| `-Force` | Не задавать интерактивных вопросов (не показывать меню версий, брать `LlamaCppVersion` из INI или `latest`, не спрашивать про переустановку). |
| `-ForceDownload` | Принудительно перекачать архивы, даже если они есть в кэше `Downloads`. Также сбрасывает кэш списка релизов. |
| `-Upgrade` | Режим автообновления: включает `-Force`, ставит `LlamaCppVersion=latest`. Предназначен для планировщика. |
| `-NoPause` | Не ждать нажатия Enter в конце (для CI/CD и Планировщика). |
| `-ConfigPath` | Путь к нестандартному INI-файлу. |

## Автообновление (Планировщик Windows)

1. Откройте **Планировщик заданий** (Task Scheduler).
2. Создайте задачу с триггером (например, ежедневно в 3:00).
3. В действии укажите:
   - **Программа**: `powershell.exe`
   - **Аргументы**: `-NoProfile -ExecutionPolicy Bypass -File "D:\AI\Llama.cpp\install\llama-windows-install.ps1" -Upgrade -NoPause`
4. Включите опцию **«Выполнять с наивысшими правами»** (Run with highest privileges).
5. (Опционально) Настройте условие «Запускать задачу, только если компьютер подключен к сети».

Лог работы будет писаться в `D:\AI\Llama.cpp\install\llama-windows-install.log`.

## Сценарии

| Хочу... | Действие |
|---|---|
| Обновиться с b12184 → b12200 | Запустить скрипт → выбрать `[1] b12200` → подтвердить |
| Даунгрейд с b12200 → b12184 | Запустить скрипт → выбрать нужную версию |
| **Переустановить текущую** | Запустить скрипт → выбрать версию с пометкой `(переустановка)` → подтвердить |
| Отменить обновление | Запустить скрипт → нажать `s` в меню (служба не тронута) |
| Тихо переустановить (без вопросов) | `-Force` + `LlamaCppVersion=latest` в INI |
| Первичная установка | Запустить на «чистой» машине — меню без пометки текущей |
| Автообновление по расписанию | `-Upgrade -NoPause` в планировщике |

## Удаление

```powershell
# Удалить службу, сохранив модели, бэкапы и архивы
.\llama-windows-uninstall.ps1

# Полная очистка (включая модели, архивы и бэкапы)
.\llama-windows-uninstall.ps1 -PurgeModels -PurgeLlamaCpp -PurgeLogs -PurgeDownloads -PurgeBackup -Force -NoPause
